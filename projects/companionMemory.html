Audience-Scoped Memory for Companion Agents

A companion-agent memory system plus a study of how shared state leaks secrets between household members. On BOND-Bench, naive RAG leaks in 100% of probes; audience-scoped memory leaks 0% while keeping 90% recall@3.

A home companion agent talks to several people. If it remembers something one person told it in confidence and later lets it slip to someone else, it has broken trust — even if it never retrieves that memory directly. Hints can leak through what it chooses to bring up, how it ranks memories, or simply its mood.

I built a companion-agent "brain" with human-like memory — write gating, forgetting curves, gist decay and multi-factor retrieval — plus a face / voice person registry and proactive behaviour, and used it to study where confidential information leaks and how to close every channel.

Highlights

  • Thesis: any state an agent shares across audiences is a leak channel, and partitioning that state by audience closes it. Six channel types identified and closed — memory slots, write-time novelty, the perceived-audience key, the proactivity gate, calibration and affect carry-over.
  • Audience uncertainty must be handled conservatively: over-estimating who is listening never leaked (0 / 22,090 cases), while under-estimating did (12.6–18.9%).
  • Verification-first engineering: a bounded check over 32,768 trajectories, 114 unit tests, and every number in the paper auto-checked against the code.
