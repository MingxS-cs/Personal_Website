Planning App

Developed a cross‑platform planner in Python using object‑oriented techniques. The application features yearly, monthly and daily dashboards and allows users to add custom modules such as checklists, timers, notes, photos, recordings and file uploads. Each module can be scheduled and colour‑coded to create an intuitive calendar interface.
