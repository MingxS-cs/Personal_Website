Planning App

A modular Python planner with yearly, monthly and daily views, built with object-oriented design.

Python OOP

Developed a cross‑platform planner in Python using object‑oriented techniques. The application features yearly, monthly and daily dashboards and allows users to add custom modules such as checklists, timers, notes, photos, recordings and file uploads. Each module can be scheduled and colour‑coded to create an intuitive calendar interface.

Highlights

  • Yearly / monthly / daily views share one underlying data model — a single edit propagates everywhere.
  • Pluggable module system: checklist, timer, note, photo, recording and file modules all implement a common interface.
  • Colour‑coded scheduling and consistent calendar layout for quick visual scanning.
