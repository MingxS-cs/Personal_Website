Learning Grasp Success in Simulation

Simulated 2,000 grasps with a Robotiq 2F-85 and a three-finger SDH hand on cubes and spheres in PyBullet, then trained an MLP to predict grasp success from pose — packaged as a clean OOP command-line pipeline.

A simulation-to-learning pipeline for grasping. Grippers attempt grasps on cubes and spheres in PyBullet; a grasp counts as successful only if the fingers hold sustained contact with the object. Each attempt is logged with its pose and outcome, and a neural network learns to predict success from the pose alone.

Dataset — success rate by gripper and object

Two-finger · cube24.4%
Two-finger · sphere62.2%
Three-finger · cube34.6%
Three-finger · sphere28.8%

2,000 simulated grasps (4 gripper–object pairs × 500), split 80 / 20 into 1,600 training and 400 test samples.

Highlights

  • Clean object-oriented design: an abstract Gripper base class with two-finger and three-finger subclasses that share connection, contact checks and data logging.
  • Single CLI entry point with subcommands — collect, merge, split, train and test — so the whole pipeline is reproducible from one script.
  • Grasp-success classifier: a z-score-normalised MLP (9 → 64 → 32 → 1) on position, orientation quaternion, object and gripper IDs, reporting a confusion matrix, precision, recall and F1.
