A‑Share Transformer Stock Predictor

2025 · PyTorch · Transformer · Time‑series Forecasting

An end‑to‑end pipeline that pulls daily price/volume data for the A‑share main board, engineers a rich set of technical indicators, fuses the Shanghai Composite as a market‑context signal and feeds them into a Pre‑LN Transformer to forecast next‑day returns. The model is hardened against the usual time‑series pitfalls — causal masking, padding handling, FP32 softmax and triple sequence aggregation.

Pipeline

  • Auto‑collects A‑share main‑board data, excluding ChiNext / STAR Market / ST stocks.
  • Computes MA(5/10/20/80), MACD, KDJ, RSI, BOLL, OBV and Williams %R as input features.
  • Fuses the Shanghai Composite trend so the model can condition on overall market context.
  • Train · evaluate · predict commands all share one CLI (run.py all / collect / process / train / predict).

Model Design

  • Input LayerNorm + optional tanh compression (replaces hard clamping for cleaner gradients).
  • Pre‑LN Transformer encoder for stable training and stronger generalisation than the post‑LN baseline.
  • Numerically robust attention: finfo(min) instead of -inf, softmax in FP32, NaN→0, joint key+query padding.
  • Triple sequence aggregation — last_valid + masked_mean + attention pool — better suited to causal forecasting.
  • Mixed‑precision (FP16) training, early stopping, configurable model sizes (small / base / large).
