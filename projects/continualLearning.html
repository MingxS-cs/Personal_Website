Sleep-Time Memory Consolidation for LLM Agents

Consolidates conversation memories into model weights offline (sparse FFN updates, replay, EWC) behind a runtime that supports barge-in, suspend and resume — 9.5 ms interrupt latency and 164× smaller low-rank checkpoints.

Companion agents pick up new knowledge in conversation, but retrieval alone never changes the model itself. This project consolidates memories into the weights during "sleep" — offline sessions between conversations — using sparse FFN neuron selection, interleaved replay and EWC, behind a runtime that can be interrupted mid-sentence and resumed safely.

Highlights

  • Runtime with barge-in, suspend / resume and deferred writes, so learning never corrupts the model mid-conversation.
  • Masking the constrained object's tokens during training removed the harm of naive "statement" training (−0.074 → +0.002), replicated over 5 seeds on 2 models.
  • Research hygiene: retracted earlier retention claims after finding a benchmark bug, and logged 17 falsified mechanisms instead of hiding them.
